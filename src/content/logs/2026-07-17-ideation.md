## Overview

#### Constraints
First group meeting. Discussed general interest as well as our criteria for a 'good' projects, namely:

- A good scope:
  - How hard is the task (shouldn't be too hard/easy)
  - How well the task is defined
  - How well is it scoped out
- Should be cool - enough 'wow factor' so that all members are interested and motivated

#### Project Proposals
Next, each member set forth an initial proposal. The goal of this was to bring different areas to the table and spark discussion - not to finalize on a project in this meeting.

The projects set forth were:
 1. A pipeline/tool which would help in actuator design. Rather than users designing actuators based on their constraints, then receiving a prototype/part which doesn't perform as expected in real world, the proposed tool would model actuators better based on different learned approaches and real world data so reduce the discreptancy in modeled and real actuators. 
 2. Martian Habitat Building. The main goal for most space research/industry, is Mars. Colonization and habitat buildin is an area where robotic swarms could be deployed as low cost solutions able to collaborate through stigmergic signaling and build habitats larger than themselves, while being human habitable.
 3. A swarm robotics project aimed at using multiple robots to transport/manipulate difficult objects; both in size as well as soft body objects.

 5. A sports companion that is able to help in solo training in various sports. Examples include setting spikes for volleyball, passing and shooting drills for soccer, ball recovers, metrics gathering, and filming.
