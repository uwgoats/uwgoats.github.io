## Overview

With the problem defined, we built a first low-fidelity prototype to test the
core interaction before investing in polish.

## What changed

- Simplified the primary flow from 5 steps to 3
- Cut a feature that tested poorly with users
- Added a fallback state for the empty/error case

## Feedback highlights

Users found the terminology confusing in one spot. Reworded copy and re-tested.

## Next steps

- Second round of prototyping with updated copy
- Start visual design pass
