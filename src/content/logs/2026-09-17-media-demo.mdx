## A single inline photo

Regular markdown image syntax works for any image placed next to this file:

```md
![Alt text](./my-photo.jpg)
```

Live example, rendered from an actual file next to this entry:

![Demo photo](./demo-photo.svg)

## A YouTube video

```mdx
<Video youtube="jNQXAC9IVRw" caption="Optional caption" />
```

<Video youtube="jNQXAC9IVRw" caption="Example YouTube embed" />

## A local video file

Drop the file in `public/videos/`, then reference it with the path relative
to `public/`:

```mdx
<Video src="videos/demo.mp4" caption="Optional caption" />
```

See the README for the full guide, including how to add a photo gallery via
frontmatter.
